# tests

Dieser Ordner enthält automatisierte Tests für das Projekt.

Struktur:
- `semantic_core/`: Tests für den semantischen Kern und Identitätslogik.

## Funktionen

- Ermöglicht die Prüfung von Komponenten, Schnittstellen und Datenmodellen.
- Dient als Grundlage für Qualitätssicherung und Regressionstests.

## Ziel

Stellt sicher, dass zentrale Teile des Projekts funktionsfähig bleiben und Änderungen keine unerwarteten Fehler einführen.
