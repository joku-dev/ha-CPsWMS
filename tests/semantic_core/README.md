# tests/semantic_core

Dieser Ordner enthält Tests für die semantischen Kernmodule und die Identity-/Normalization-/Ontology-Logik.

## Funktionen

- Validiert Canonical-Entity-Auflösung, Normalisierung und temporale Modellfunktionen.
- Prüft das Zusammenspiel der Kernmodule mit den semantischen Datenmodellen.

## Ziel

Die Stabilität des zentralen semantischen Kerns durch automatisierte Testfälle sicherzustellen.
