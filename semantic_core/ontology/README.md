# semantic_core/ontology

Dieser Ordner bietet Ontologie-Mapping und Wissensmodellierung zur semantischen Klassifizierung.

Enthaltene Dateien:
- `ontology_mapper.py`: Klassen für das Mapping von Entitäten und Attributen auf Ontologiebegriffe.
- `ontology_store.py`: Speicherung und Abfrage von Ontologie-Begriffen, Taxonomien und Kategoriezuordnungen.

## Funktionen

- Stellt Begriffsrelationen und semantische Rollen zur Verfügung.
- Erleichtert die Klassifikation und Gruppierung von Entities anhand einer Ontologie.
- Versorgt Enricher mit zusätzlichen semantischen Kontextinformationen.

## Ziel

Die Verbindung zwischen Rohdaten und einem strukturierten Wissensnetz zu schaffen, um semantische Schlüsse zu ermöglichen.
