# semantic_core/causal

Dieser Ordner enthält die kausale Schicht des semantischen Kerns.

Enthaltene Dateien:
- `causal_dependency.py`: Logik zur Modellierung kausaler Beziehungen und zur Bewertung von Abhängigkeiten zwischen Entitäten.

## Funktionen

- Repräsentiert Ursache-Wirkungs-Pfade im semantischen Graph.
- Unterstützt die Erzeugung von kausalen Metadaten, die Enrichern und Analyse-Workflows zur Verfügung stehen.

## Ziel

Kausale Beziehungen als erster semantischer Schritt in Richtung Fehlerursachenanalyse und automatisierter Handlungsempfehlungen bereitzustellen.
