# semantic-enrichment/prompts

Dieser Ordner enthält die prompt-basierten Systemanweisungen für jeden einzelnen Enricher.

Dateien:
- `anomaly_detection.md`
- `automation_intent.md`
- `capability_mapping.md`
- `causal_dependency.md`
- `dependency_reasoning.md`
- `failure_impact.md`
- `fault_analysis.md`
- `recommended_actions.md`
- `room_inference.md`
- `semantic_descriptions.md`
- `semantic_roles.md`
- `simulation_readiness.md`
- `temporal_event_model.md`

## Funktionen

- Definiert den Kontext, die Fragen und die strukturierte Ausgabeerwartung jedes Enrichers.
- Stellt sicher, dass die LLM-Aufrufe konsistent und wiederholbar sind.

## Ziel

Sammeln aller Prompt-Vorlagen an einem Ort, um Enricherverhalten und semantische Anforderungen zentral zu steuern.
