# world-model-chat/prompts

Dieser Ordner enthält Prompt-Templates für die Chat-Service-Logik.

Enthaltene Dateien:
- `answer_generation.md`: Vorlage für die Generierung von Chat-Antworten basierend auf dem Graphkontext.
- `cypher_generation.md`: Vorlage zur Umwandlung von Nutzeranfragen in gültige Cypher-Abfragen.

## Funktionen

- Liefert den sprachlichen Rahmen für die Chat-Engine.
- Sorgt dafür, dass natürliche Sprache in strukturierte Anweisungen übersetzt wird.

## Ziel

Die Prompt-Vorlagen als zentrale Steuerung für den Chat-ausgabeprozess zu nutzen.
